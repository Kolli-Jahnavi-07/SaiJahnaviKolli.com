Snowflake incremental ELT (CDC)

Files land in S3 and Snowpipe loads them as they arrive. Streams capture exactly what changed, and a Task graph merges only those changes into current-state tables, SCD Type 2 history and a daily mart, with no full reloads. Tested end to end against late, duplicate and invalid data, including tasks that fail mid-run.

Snowflake (Snowpipe, Streams, Tasks), SQL, Python, AWS S3, GitHub Actions
